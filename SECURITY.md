# Security Policy

Do not report security vulnerabilities in public issues or Discussions. Share
the minimum necessary detail privately with an H-CAM organization owner through
an approved private channel.

Do not include credentials, access tokens, secret references, personal data,
Government/private data, police records, camera media, exploit payloads, or
infrastructure identifiers in public repositories, issues, pull requests, or
Project fields.

Security reports should identify the affected repository and release or commit,
the impact, safe reproduction conditions, and a contact method. Do not test
against cameras, networks, accounts, or services you do not own or have explicit
authorization to assess.
