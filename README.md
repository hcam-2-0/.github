# H-CAM GitHub Community Health

This public repository provides the default community-health files used across
the H-CAM GitHub organization:

- organization profile and repository navigation;
- structured issue forms for bugs, features, architecture, decisions, research,
  phase gates, and risk/compliance work;
- the default pull-request template and contribution workflow;
- security reporting, support, and governance guidance.

It contains no product source code, operational credentials, camera media, or
deployment configuration. Current delivery status is maintained in the
[H-CAM Platform Delivery project](https://github.com/orgs/hcam-2-0/projects/1).
