# H-CAM Support And Coordination

- Use the [H-CAM Platform Delivery project](https://github.com/orgs/hcam-2-0/projects/1)
  for current status, priorities, phases, and gates.
- Use [hcam-docs Discussions](https://github.com/hcam-2-0/hcam-docs/discussions)
  for architecture questions, planning, and cross-repository proposals.
- Use the structured issue form in the repository that owns the affected
  capability for actionable work.
- Use a pull request for implementation and validation evidence.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose a
  vulnerability or sensitive evidence in an issue or Discussion.

H-CAM is not currently offered as a public production service. Repository
access or demo material does not grant access to cameras, Government systems,
private data, models, datasets, or deployment environments.
